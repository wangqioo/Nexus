# 码迹 · 新手指南

码迹（Nexus）做两件事：**项目管理** + **开发经验管理**。

- **项目管理**：用多种灵活方式导入项目（本地 / GitHub / 批量扫描），AI 自动分析类型并分类归档，还会生成**项目概括名**和**项目简介**，在列表里一目了然。
- **经验管理**：把写码过程中产生的调试经验、代码片段、笔记，从「散落在各项目里」变成「可检索、可复用的知识库」。

**最核心一句话**：按照 .nexus 执行，提取知识文档并归类。

本指南讲清**逻辑**和**使用方法**，方便你快速上手。

---

## 一、码迹在解决什么问题？

- **项目一多就乱**：文件夹一堆，哪个是啥、干啥的，光看目录名想不起来。码迹帮你：导入时 AI 分析项目，生成**概括名**和**简介**，按类型自动分类，在项目列表里一眼就能看懂每个项目是啥。
- **经验散落难复用**：踩过的坑、写过的片段、记的笔记分散在各个仓库里，想复用时要靠记忆或满盘搜。码迹做的事：**项目级记录 + 中央知识库**。你在每个项目里照常记（调试/片段/笔记），码迹帮你同步到一台「总库」（`~/.nexus/`），之后按类型、关键词检索，跨项目复用。

## 二、核心逻辑：两处存储，一条流水线

### 2.1 两处存储

| 位置 | 是什么 | 谁在用 |
|------|--------|--------|
| **项目里的 `.nexus/`** | 当前项目的调试经验、代码片段、笔记、配置模板等 | 你在 Cursor 里开发时，随写随存 |
| **本机的 `~/.nexus/`** | 所有项目汇总后的「中央知识库」+ 笔记库 | 码迹 App：检索、浏览、跨项目复用 |

关系一句话：**项目内 `.nexus` 是「输入端」，`~/.nexus` 是「汇总库」；同步 = 把输入端的新内容写入汇总库。** 精华概括：**按照 .nexus 执行，提取知识文档并归类。**

![建议配图：左侧「项目 A/B/C 的 .nexus」→ 同步 → 右侧「~/.nexus 知识库 + 笔记」](images/guide-02-storage.png)

### 2.2 一条流水线（推荐使用顺序）

```
导入项目 → 在 Cursor 里开发、记录 → 回到码迹「一键同步」→ 知识库/笔记里可查
```

1. **导入项目**：在码迹里把项目「登记」进来（GitHub / 本地文件夹 / 批量扫描），并让码迹在项目里创建好 `.nexus` 目录。
2. **开发与记录**：用 Cursor 打开项目，在写码时用自然语言让 AI 帮你记调试经验、代码片段、笔记（都会落到 `.nexus/` 对应子目录）。
3. **同步到知识库**：回到码迹，点该项目的「一键同步」，把 `.nexus` 里新增/修改的内容同步到 `~/.nexus`，之后在「知识库」「笔记」里就能检索、复用。

![建议配图：三步流程图 ① 导入 ② Cursor 记录 ③ 一键同步](images/guide-03-pipeline.png)

## 三、第一步：导入项目

入口：码迹左侧 **「项目」** → 右上 **「导入项目」**。

![建议配图：项目管理页，高亮「导入项目」按钮](images/guide-04-import-entry.png)

### 三种导入方式

| 方式 | 适合场景 | 操作要点 |
|------|----------|----------|
| **本地项目** | 电脑上已有项目文件夹 | 选文件夹 → 点「AI 分析」→ 自动归类并写入项目列表，无 `.nexus` 会自动创建 |
| **GitHub** | 从仓库克隆到本地再管理 | 填仓库地址 → 克隆完成后 AI 分析 → 自动归类并创建 `.nexus` |
| **批量扫描** | 一个父目录下有很多项目 | 选父目录 → 扫描出未导入项目 → 批量 AI 分析并归档 |

**共同逻辑**：都会用**智谱 AI** 分析项目类型（如 MCU / 软件 / AI 等），并据此把项目归档到对应分类；同时生成**项目概括名**和**项目简介**，在项目卡片上直接展示，让你一目了然。若 AI 无法归类，会提示你「创建新类型」或「按推荐占比选已有类型」。

- **使用 AI 分析前**：请在 **「设置」→「智谱 API Key」** 中填写 Key，否则仅做本地检测、不自动分类、不生成概括名与简介。
- 导入成功后，项目会出现在项目列表（带概括名、简介、类型标签）；若该项目之前没有 `.nexus`，码迹会自动用**同一份模板**在项目里创建 `.nexus` 目录结构。

![建议配图：导入弹窗，三个 Tab「本地项目 / GitHub / 批量扫描」](images/guide-05-import-modes.png)

## 四、第二步：在 Cursor 里开发并记录

### 4.1 从码迹打开项目

在项目列表中，找到项目，点击 **「在 Cursor 打开」**。码迹会把该项目路径交给 Cursor，Cursor 打开后能识别该项目下的 `.nexus`，并应用对应规则。

![建议配图：项目卡片上的「在 Cursor 打开」按钮](images/guide-06-open-cursor.png)

### 4.2 项目里的 `.nexus` 长什么样？

每个已导入并初始化过的项目，根目录下会有一个 `.nexus/`，结构如下（所有项目共用同一套模板，不按项目类型区分）：

```
.nexus/
├── project.yaml    # 项目配置（名称、类型等）
├── notes/          # 开发笔记 → 同步后只在「笔记」面板展示
├── debug/          # 调试经验
├── snippets/       # 代码片段
├── configs/        # 配置模板
└── other/          # 其他
```

- **笔记**：只存在 `.nexus/notes/`，同步后进入 `~/.nexus/notes/`，只在码迹的「笔记」里看。
- **知识库**：调试/片段/配置/其他四类，同步后进入 `~/.nexus/knowledge/<项目类型>/`，在「知识库」里按类型检索。

### 4.3 在 Cursor 里怎么记？

在 Cursor 里用自然语言让 AI 帮你写进 `.nexus`，例如：

- *「帮我记录一下这个 WS2812 闪烁问题的解决方案」* → 会落到 `debug/`
- *「把这段 IMU 初始化代码保存到 nexus」* → 会落到 `snippets/`
- *「记个笔记：I2C 时钟频率限制」* → 会落到 `notes/`

只要项目里有 `.nexus` 且 Cursor 规则生效，这些内容都会按类型进入对应子目录。

![建议配图：Cursor 里与 AI 对话记录经验的示例](images/guide-07-cursor-record.png)

## 五、第三步：回到码迹，一键同步

### 5.1 同步做什么？

- 扫描该项目的 `.nexus/` 下**新增或修改**的文档。
- 把笔记同步到 `~/.nexus/notes/`，把调试/片段/配置/其他同步到 `~/.nexus/knowledge/<项目类型>/`。
- 若在「设置」里开启了「同步时用 AI 分析」并已配置智谱 API Key，同步时还会用 AI 补全标题、标签等，便于后续检索。

### 5.2 怎么操作？

在**项目**页，找到对应项目，点击该项目的 **「一键同步」**（或「一键导入」）。同步完成后，在左侧 **「知识库」** 和 **「笔记」** 里即可看到刚同步的内容。

![建议配图：项目卡片上的「一键同步」与同步后知识库/笔记入口](images/guide-08-sync.png)

### 5.3 项目详情里的「笔记」「知识库」

点进项目后，在项目详情里会有 **「笔记」**、**「知识库」** 等 Tab，展示**已同步到中央库的、属于该项目的**笔记和知识条目，可点击某条直接跳转到「笔记」页或「知识库」页查看详情。

## 六、知识库与笔记在码迹里怎么用？

- **知识库**（左侧菜单）：按项目类型、分类（调试经验 / 代码片段 / 配置模板 / 其他）浏览和搜索；所有已同步项目的知识都会在这里汇总。
- **笔记**（左侧菜单）：只看笔记类内容，同样支持搜索和筛选；来源仍是各项目 `.nexus/notes/` 同步上去的条目。

两者都支持关键词搜索，方便你跨项目复用经验。

![建议配图：知识库页 / 笔记页的列表与搜索](images/guide-09-knowledge-notes.png)

## 七、建议你先做的几件事

1. **配置智谱 API Key**（若要用 AI 分析和同步补全）：**设置** → **智谱 API Key** → 填写并保存。
2. **导入一个项目**：用「本地项目」或「GitHub」导入一个你正在写的项目，确认列表里出现且带有 `.nexus`。
3. **用 Cursor 打开该项目**：在项目里用上面那类自然语言试记一条调试经验或笔记，确认 `.nexus` 对应目录下多了文件。
4. **回到码迹点「一键同步」**：再打开「知识库」或「笔记」，确认刚记的内容已经出现。

做完这一轮，整条「导入 → 记录 → 同步 → 检索」的链路就通了；之后按同样方式管理更多项目即可。

## 八、常见问题简答

- **不填 API Key 可以吗？**  
  可以。不填则不会做 AI 分类与同步时的 AI 补全，但本地导入、同步、浏览知识库/笔记都可用。

- **`.nexus` 要自己建吗？**  
  不用。在码迹里「导入项目」且该项目还没有 `.nexus` 时，码迹会自动用统一模板创建。

- **笔记和知识库的区别？**  
  笔记只来自 `.nexus/notes/`，只在「笔记」里展示；知识库来自 debug/snippets/configs/other，在「知识库」里按类型展示。两者都在 `~/.nexus/` 有对应存储。

- **多个电脑怎么用？**  
  码迹的数据在本地 `~/.nexus/`，多机需要自己备份或同步该目录；项目本身若用 Git 管理，`.nexus` 可提交到仓库，在另一台机器拉代码后，用码迹再导入/同步即可。
