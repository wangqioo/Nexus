# 扩展指南：项目类型与知识分类

## 一、知识库与笔记库

- **知识库**只允许 **4 类**：调试经验、代码片段、配置模板、其他。**.nexus 使用一份统一模板**，不按项目类型区分。
- **笔记库**：`.nexus/notes/` 下的文档同步到 `~/.nexus/notes/`，**仅在笔记面板展示**，按项目类型分类。笔记不入知识库。
- 归档路径：
  - 知识库：`~/.nexus/knowledge/<项目类型>/*.json`（扁平），每条条目的 `category` 为上述 4 类之一。
  - 笔记库：`~/.nexus/notes/*.json`，每条笔记可带 `projectType`，用于笔记面板按项目类型筛选。

## 二、.nexus 目录与分类对应

| .nexus 子目录 | 归属     | 说明           |
|---------------|----------|----------------|
| `notes/`      | 笔记库   | 开发笔记等（仅笔记面板） |
| `debug/`      | 知识库   | 调试经验       |
| `snippets/`   | 知识库   | 代码片段       |
| `configs/`    | 知识库   | 配置模板       |
| `other/`      | 知识库   | 其他           |

未在上述列表中的子目录（如原项目自建的目录）同步时会归入知识库的「其他」类。

## 三、导入项目与提取文档的 Skills

- **导入项目**：初始化 `.nexus` 时统一使用一份模板配置（应用内「模板设置」），会创建 5 个子目录（notes、debug、snippets、configs、other），并写入对应的 Cursor 规则（`.cursor/rules/nexus.mdc`）。Skills 中应说明「知识库仅 4 类，笔记仅存于笔记库（笔记面板）；.nexus 不按项目类型区分」。
- **提取文档**：从项目内提取经验文档时，应按照上述 4 类知识 + 笔记库归类保存到对应 `.nexus` 子目录，便于同步后知识库/笔记库与分类一致。

## 四、新增项目类型

新增项目类型时，.nexus 仍使用同一份模板，无需为不同类型再定义不同知识分类。只需在 main 的 `PROJECT_TYPE_DEFS`、前端的 `ProjectType` 与 `PROJECT_TYPES` 中增加新类型即可。

## 五、数据存储

- 自定义项目类型：`~/.nexus/custom-project-types.json`
- 知识库：`~/.nexus/knowledge/<项目类型>/*.json`
- 笔记库：`~/.nexus/notes/`

无需与外部数据库同步，Nexus 直接读写上述路径。
