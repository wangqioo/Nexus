# 码迹（Nexus）

**项目管理 + 开发经验管理**：按 `.nexus` 执行，提取知识文档并归类，从项目创建到知识沉淀的完整工作流。

---

## 一句话

**按照 .nexus 执行，提取知识文档并归类。**

在项目里用 Cursor 记录调试经验、代码片段、笔记，回到码迹一键同步；码迹按 `.nexus` 结构提取并归类到中央知识库与笔记库，跨项目检索复用。

---

## 功能概览

| 模块 | 说明 |
|------|------|
| **项目管理** | 本地 / GitHub / 批量扫描导入，AI 自动分类、生成概括名与简介，卡片一目了然 |
| **知识库** | 调试经验、代码片段、配置模板等，按项目类型分目录，全局检索 |
| **笔记库** | 开发笔记单独存放，与知识库并列，统一检索 |
| **开发库** | 常用芯片厂商例程的快速链接，一键打开或克隆到本地（可选） |

### 核心流程

```
导入项目 → AI 分类 + 概括名/简介 → 在 Cursor 里记录 → 一键同步 → 知识库/笔记库检索复用
```

- **导入**：多种方式添加项目，AI 分析类型并生成概括名、简介，自动创建 `.nexus` 目录。
- **记录**：在 Cursor 中用自然语言让 AI 帮你记（如「帮我记录这个 bug 的解决方案」「把这段代码保存到 nexus」「记个笔记：I2C 时钟限制」），内容落入 `.nexus/` 对应子目录。
- **同步**：回到码迹点「一键同步」，按 .nexus 执行，提取知识文档并归类到 `~/.nexus/` 知识库与笔记库。
- **复用**：在「知识库」「笔记库」中按类型、关键词检索，跨项目复用。

---

## .nexus 目录

每个项目下的 `.nexus/` 由码迹统一模板生成，与中央库对应关系如下：

| 子目录 | 含义 | 同步后 |
|--------|------|--------|
| `debug/` | 调试经验 | → 知识库（调试经验） |
| `snippets/` | 代码片段 | → 知识库（代码片段） |
| `configs/` | 配置模板 | → 知识库（配置模板） |
| `notes/` | 开发笔记 | → 笔记库 |
| `other/` | 其他 | → 知识库（其他） |

---

## 大模型 API（可选）

导入与同步时的 AI 分析（项目分类、概括名/简介、同步时补全标题与标签）需配置大模型 API。在 **设置 → 大模型 API** 中可任选其一：

- **智谱**（默认）
- **OpenAI**
- **月之暗面 Kimi**
- **MiniMax**
- **其他**（自定义 API 地址 + Key + 模型名）

不配置也可使用，仅无 AI 分类与补全；配置后即可使用上述能力。

## 快速开始

```bash
# 克隆
git clone https://github.com/wangqioo/Nexus.git
cd Nexus

# 安装与启动
npm install
npm run electron:dev
```

首次打开可按欢迎引导操作；需要 AI 分析时在「设置」→「大模型 API」中配置 Key。项目列表、知识库、笔记等数据存于 `~/.nexus/`，不随仓库提交。

### 构建安装包（macOS）

```bash
npm run electron:build:mac
```

产物在项目下的 `release/` 目录。

## 使用流程简述

1. **导入项目**：项目管理 → 导入项目 → 选本地文件夹 / 填 GitHub 地址 / 批量扫描父目录 → AI 分析并归档。
2. **在 Cursor 里记录**：项目卡片 →「在 Cursor 打开」→ 在项目里用自然语言让 AI 写入 `.nexus`。
3. **一键同步**：回到码迹 → 项目卡片 →「一键同步」→ 按 .nexus 提取并归类到知识库与笔记库。
4. **检索复用**：左侧「知识库」「笔记库」按类型与关键词检索。

更细的步骤与说明见应用内「新手指南」或 `docs/新手指南.md`。

## 技术栈

- **桌面**：Electron
- **前端**：React 18 + TypeScript + Vite
- **UI**：Ant Design 5
- **搜索**：Fuse.js
- **AI**：兼容 OpenAI 格式的 chat/completions（智谱 / OpenAI / Kimi / MiniMax / 自定义）

---

## 数据与隐私

- **应用数据**（项目列表、知识库、笔记、配置等）均在 `~/.nexus/`，**不会随本仓库提交**。
- **大模型 API Key** 仅在「设置」中配置并保存在 `~/.nexus/config.json`，他人 clone 仓库后需自行填写自己的 Key。
- 仓库中无个人路径，类型目录与开发库默认路径均基于当前用户主目录（如 `~/Workshop/...`），克隆即可在本机使用。

## Cursor Skills（可选）

若在 Cursor 中安装了码迹相关 Skills（如 `nexus-record-debug`、`nexus-record-snippet`、`nexus-record-note`），可在开发时更快触发「记录到 .nexus」的流程；未安装也可通过自然语言让 AI 写入 `.nexus`。
